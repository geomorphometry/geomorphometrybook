# Geomorphometry - Chapter 5

``coregistration_plot_figure.R`` reproduces Fig. 5.5

``geomorphometry_geostatistical_simulation.R`` produces Fig. 5.14 - 5.17. This script uses Ponui island DTM (the example DTM used in this book) and FABDEM version V1.2 tile S37E175_FABDEM_V1-2. The FABDEM tile is too large to ship with this repo, so please download either from [here](http://data.bris.ac.uk/data/dataset/s5hqmjcdj8yo2ibzi9b4ew3sn) or through this handy [python package](https://github.com/jantomec/fabdem) Te extent geopackage is in ``\data\ponui_extent.gpkg``

Fig. 5.4, 5.7, 5.10 and 5.12 were created by John Lindsay and the code is available upon request.

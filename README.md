# Geomorphometry - Concepts, Software, Application 
Editors: Reuter, Grohmann, Lecours

Paperback ISBN: 9780443333767 eBook ISBN: 9780443333774 DOI:https:/doi.org/10.1016/C2023-0-52503-0 

To Mother Nature, for shaping the Earth so that we can measure it and see beauty in our geovisualizations.

Geomorphometry, the science of quantitative land-surface analysis, evolved from geomorphology and quantitative terrain analysis. It is rooted in 19th-century geometry and physical geography. Since this book's first edition in 2009, there have been significant advancements in data used for geomorphometry, their production methods, the software to process and analyze them, and their applications. This repository contains code examples used the three different sections of the book: I) the concepts, II) the software, and III) the applications. The common dataset that was provided to all contributors for use as a case study can be found on [ZENODO](https://zenodo.org/records/18314107).

In case you observe an issue with the execution of the codes in the respective chapters, please create a bug request including the steps for replication. If you can fix it yourself please be so kind submit a PR.

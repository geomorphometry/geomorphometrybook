# Geomorphometry Using Open-Source Programming Languages: R

This section of the repository contains code needed to run the R code examples from the chapter "Geomorphometry Using Open-Source Programming Languages" from the second edition of the book *Geomorphometry: Software, Concepts, Applications*.

R and RStudio can be downloaded and installed from https://posit.co/download/rstudio-desktop/

## Packages

Open R/RStudio to install dependencies and run the script `Install_Packages/R_install_pkgs.R`.

## Chapter Code

To follow along with the R code from the chapter, open and run the examples in the script `R_script.R`.
The easiest way to run this code is to open the R project in RStudio by opening the 
`Geomorphometry_Programming_Code.Rproj` file, though RStudio is not strictly needed. 
The working directory is explicitly set as R subfolder of this project.
